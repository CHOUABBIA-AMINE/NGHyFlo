# NGHyFlo

NGHyFlo is the clean target repository for an enterprise-grade industrial pipeline operations platform for Sonatrach.

This repository is being initialized documentation-first. It must strategically evolve HyFlo by analyzing two read-only references before implementation begins:

- **HyFloAPI** for business, domain, and accumulated pipeline operations knowledge.
- **NGHyFloAPI** for architecture, documentation, standards, roadmap, audit, and implementation lessons.

The current workspace contains only this target repository, so implementation is intentionally gated until the reference repositories are available and analyzed.

Start with the [documentation baseline](docs/README.md).
