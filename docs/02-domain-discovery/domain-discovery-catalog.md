# Domain Discovery Catalog

This catalog is a placeholder for the domain knowledge that must be extracted from HyFloAPI and reconciled with lessons from NGHyFloAPI.

## Catalog status

Status: **not started**.

Reason: HyFloAPI and NGHyFloAPI are not available in the current workspace.

## Required catalog sections

When the reference repositories are available, populate the following sections.

### Business capabilities

Document each capability with a description, operational owner, source evidence, and unresolved questions.

### Operational workflows

Document workflows such as monitoring, nomination, allocation, transport, measurement validation, incident handling, reporting, or other workflows discovered in the reference systems.

### Domain model candidates

For each candidate concept, document:

- Name.
- Definition.
- Source evidence.
- Related concepts.
- Lifecycle states.
- Business invariants.
- Data sensitivity.
- Audit requirements.

### Business rules and calculations

For each rule or calculation, document:

- Rule statement.
- Source evidence.
- Inputs and outputs.
- Units of measure.
- Error handling expectations.
- Operational impact if incorrect.

### Integrations and external dependencies

For each integration, document:

- External system or data provider.
- Business purpose.
- Data exchanged.
- Frequency or triggering event.
- Reliability and reconciliation expectations.

### Open questions

Track gaps that require stakeholder clarification before implementation begins.
